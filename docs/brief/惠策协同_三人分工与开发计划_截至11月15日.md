## 5. 接口契约总则

**统一前缀：**`/api/v1`。HTTP JSON 字段统一用 `camelCase`；ID 用 UUID 字符串；时间用带时区的 ISO 8601 字符串，数据库统一 UTC；金额和精度敏感数字用十进制字符串，如 `"3000000.00"`，不使用 JS 浮点数传递。事实未知为 `null` 或缺字段，**不能解释成 0**。政策原文链接必须为官方 HTTPS URL。列表响应使用 `{items, nextCursor}`，`nextCursor=null` 表示结束；一次最多 50 条。

**身份与边界：**演示站整体使用网关限制访问；`/admin/*` 与轨迹接口再做后台访问控制。演示环境只存合成企业资料，API Key 仅在服务端环境变量。任何接口都不得根据模型推断补全未经用户提供的财务事实。

**统一错误：**非 2xx 返回 `{"error":{"code":"VALIDATION_ERROR","message":"可执行的中文说明","details":{}},"traceId":"UUID"}`。常用状态码：`400` 格式错误、`401/403` 无权限、`404` 未找到、`409` 版本冲突或审核冲突、`422` 业务校验失败、`429` 上游限流、`503` MaaS/数据库不可用。内部堆栈、连接串和密钥不能返回前端。

### 5.1 端点表（M1 实现，M2 按此联调）

| ID | 方法与路径 | 主要请求约束 | 成功输出与副作用 | 典型失败 |
| --- | --- | --- | --- | --- |
| API-01 | `GET /health` | 无请求体；无需暴露连接详情 | `200 {status:"ok",version}` | 服务未就绪时 `503` |
| API-02 | `GET /policies?status=&type=&cursor=` | `status=published/closed`；`type=tax/grant`；最多 50 条 | `200 {items:[PolicySummary],nextCursor}`；仅公开已审核内容 | 参数非法 `400` |
| API-03 | `GET /policies/{policyId}` | UUID；可指定 `version`，默认最新已发布版 | `200 PolicyDetail`，含官方来源、版本、窗口、可公开引用的条件 | 无记录 `404` |
| API-04 | `POST /admin/policies/import` | `multipart/form-data`：`metadata` JSON（官方 URL、标题、机关、地区、类型、有效期等），可带 PDF/附件；单文件上限 10 MB，最多 5 个 | `201 PolicyDraft`；仅建立待审核版本，不自动发布 | 来源/文件不符 `422`，重复版本 `409` |
| API-05 | `POST /admin/policies/{policyId}/extract` | 仅待审核版本；可传 `modelVersion`；同版本重复调用需幂等 | `200 {criteriaDrafts,validationFindings,usage}`；抽取失败保留原文 | 模型不可用 `503` |
| API-06 | `PUT /admin/policies/{policyId}/criteria` | `If-Match` 为当前版本标识；提交 `CriterionDraft[]` 与原文 span | `200 {criteria,validationFindings}`；只保存草稿 | 版本冲突 `409`、引用错误 `422` |
| API-07 | `POST /admin/policies/{policyId}/publish` | 仅全部条件通过引用校验且审核人确认 | `200 PolicyDetail`；标记已发布，相关旧判断失效 | 未完成审核 `422` |
| API-08 | `POST /enterprises` | 合成企业画像；必填地区、行业、事实期间；不收统一社会信用代码、身份证等演示无关字段 | `201 Enterprise`，含 `factVersion` | 字段值/期间非法 `422` |
| API-09 | `GET /enterprises/{enterpriseId}` | UUID；受限演示站内访问 | `200 Enterprise`，事实含来源与核验状态 | 不存在 `404` |
| API-10 | `PATCH /enterprises/{enterpriseId}/facts/{factKey}` | `If-Match` 使用当前 `factVersion` 的 ETag；值、单位、所属期间、来源必填；`null` 表示未知，不可当 0 | `200 Enterprise`；更新 `factVersion` 并使依赖旧事实的判断失效 | 冲突 `409`、类型错误 `422` |
| API-11 | `POST /assessment-runs` | `enterpriseId`、`policyIds[]`（1—7 个）、`asOf`；仅匹配已发布规则 | `200 AssessmentRun`；每政策四态结果、条件结果、`nextQuestion`、`validity` | 企业不存在 `404`、未审核政策 `422` |
| API-12 | `GET /assessment-runs/{runId}` | UUID | `200 AssessmentRun`；历史运行不可被新结果覆盖 | 不存在 `404` |
| API-13 | `GET /assessment-runs/{runId}/report.md` | UUID；`Accept: text/markdown` | `200 text/markdown` 下载报告；含时间、版本、官方链接和涉税提示 | 不存在 `404` |
| API-14 | `GET /assessment-runs/{runId}/trace` | UUID；后台或演示授权 | `200 {steps:[TraceStep]}`，按步骤展示状态、依据、耗时与原文→规则→事实→结果，内容脱敏 | 无权 `403` |

### 5.2 关键数据结构与约束

| 对象 | 必有字段 | 强约束 |
| --- | --- | --- |
| `PolicySummary` | `id,title,type,issuer,region,version,status,effectiveFrom,effectiveTo,applicationWindow,sourceUrl` | `type` 仅 `tax/grant`；`status` 仅 `published/closed`；制度性税收政策的 `effectiveTo` 与 `applicationWindow` 可为 `null`；历史窗口不得出现“立即申报” |
| `CriterionDraft` | `id,expression,sourceSpan,sourceVersion,validationStatus` | `expression` 为受限 AST（`and/or/not/compare/date/industry_exclusion/quarterly_average`）；span 含页码或段落及原文片段；校验失败不得发布 |
| `EnterpriseFact` | `key,value,unit,period,source,verified` | 数值金额为十进制字符串；`period` 明确年度/季度；`source` 仅用户输入或合成材料；未知值为 `null` |
| `AssessmentRun` | `id,enterpriseId,policyVersionMap,factVersion,createdAt,assessments[]` | 一次运行不可变；重算创建新 ID，并用 `supersedesRunId` 关联旧运行 |
| `PolicyAssessment` | `policyId,result,validity,criteriaResults[],missingFacts[],nextQuestion,validUntil` | `result` 四态：`satisfied/not_satisfied/insufficient_evidence/conflict`；`validity` 独立为 `current/stale`；`validUntil` 可为 `null`，不得拿政策有效期直接替代 |
| `TraceStep` | `stage,status,inputSummary,outputSummary,evidenceRefs,policyVersion,modelOrRuleVersion,elapsedMs` | `status` 为 `ok/needs_review/retryable_error/fatal_error`；引用只指向可公开原文；不返回提示词中的密钥或真实企业数据；失败记录错误类别与人工处理 |

**一致性规则：**硬门槛不满足时结果不能是 `satisfied`；缺必要事实时不能是 `satisfied`；引用校验失败的条件不进入判断；条款冲突时结果为 `conflict`；旧结果即使原值为 `satisfied`，`validity=stale` 后前端必须显示“依据已失效，待复核”。M2 的页面状态和 M1 的返回枚举必须一一对应。
