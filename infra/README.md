# 云资源与部署（M1）

M1 在首周记录账号可用地域、RDS PostgreSQL 的 pgvector 插件支持、Redis/OBS/MaaS 连通性、实际计费与 CodeArts Skills 执行结果。MaaS API Key 只从服务端环境变量读取。资源创建与部署步骤、回滚步骤、截图或录屏证据、外网访问控制方式在此补齐。当前仅为目录骨架，不能部署。

环境基线与变量约束见根目录开发计划第 4.1 节。M1 需在此补齐：实际 Python 依赖安装命令、配置加载命令、Docker Compose/云实例初始化命令、RDS `vector` 扩展验证结果、数据库迁移、健康检查、OBS/MaaS 连通、资源地域/规格/费用上限，以及从空环境复现和回滚所需步骤。不得记录密钥、完整连接串或真实企业资料。
