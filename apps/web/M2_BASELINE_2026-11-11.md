## 消费者及迁移清单

| 页面 / client 方法和路径 | 当前行为与缓存 | E1 目标、待 M1 确认及验证（关联决策） |
| --- | --- | --- |
| 入口 / `GET /health` | 健康接口；固定样例与 HTTP 在 `App.tsx` 分支 | 健康、公开端点和无效会话优先级、失效 cookie 下登录是否可达；测新旧 cookie 真值表（D1） |
| 画像 / `POST /enterprises`、`GET /enterprises/{id}` | 页面创建合成画像；复制为新样本再次创建。企业、草稿及 ETag 仅内存 | 注册创建/恢复本人企业；普通账号不能复制创建第二家；未绑定审核员创建本人企业流程的字段与权限待定。测重复创建、刷新恢复、A/B 越权（D1/D2） |
| 补问 / `PATCH /enterprises/{id}/facts/{key}` | `If-Match`；失败读回画像并提示核对，成功后重新分析；事实和 ETag 内存 | 对象归属、审核员只读他人事实、CSRF、409/412 及响应字段确认；测冲突保留输入与跨账号操作（D1/D2） |
| 机会 / `GET /policies`、`GET /policies/{id}` | 列表分页筛选；详情按 run 的 policyVersionMap 读取并核对版本/条件；加载失败可能保留旧列表并提示 | 确认公开端点在有效/失效账号及 demo cookie 下行为、历史版本权限和字段；测旧列表与失效会话（D1/D2） |
| 分析 / `POST /assessment-runs`、`GET /assessment-runs/{id}` | 1—7 个选择创建 run；补问重算保留本页 runIds 和跳过项；requestId 抑制多处过期响应 | 服务端校验企业归属及发起人，新增历史列表恢复；退出/换账号使全部旧响应失效。测 A/B、慢响应、刷新及未知枚举（D1/D2） |
| 报告 / `GET /assessment-runs/{id}`、`GET /policies/{id}?version=`、`GET /assessment-runs/{id}/report.md` | 校验清单及历史版本，下载 Markdown；reportReady、政策详情保存在内存 | 同 run 对象鉴权；退出清理报告及下载上下文；测越权、失效、历史版本缺失（D1/D2） |
| 审核 / `GET /admin/policies`、`GET /admin/policies/{id}`、`POST /admin/policies/import`、`POST /admin/policies/{id}/extract`、`PUT /admin/policies/{id}/criteria`、`POST /admin/policies/{id}/publish` | 页面手输令牌，client 对 `/admin/` 自动附加 Bearer；草稿保存用 ETag，抽取带幂等键；未保存离开提示 | 页面令牌入口切换为审核员会话，脚本 Bearer 保留范围由 M1 定；确认写请求 CSRF、ETag、幂等和 401/403。测普通账号直连和退出后缓存（D1/D2） |
| 轨迹 / `GET /assessment-runs/{id}/trace` | 输入 run ID 或使用当前 run；自动 Bearer；401/403 清除授权，组件保护迟到响应 | 审核员全局读；企业本人轨迹必须服务端校验归属和发起人，历史无发起人不开放。确认字段与旧 Bearer 权限；测对象越权及旧响应（D1/D2） |

client 对错误读取 code/message/details/traceId，网络失败显示连接错误；对 run 四态、validity、轨迹和部分响应严格校验，未知枚举不会静默归零。E1 草案须逐字段检查必填、可空、枚举、状态码、响应示例及历史响应；单凭路径相同不能判兼容。当前 `requestId` 并非完整账号隔离机制，特别是下载和各页面各自请求需纳入切换设计。

## M2-04 初查

现有机会页按政策逐项显示结果，未见本次 run 四态汇总图；`AssessmentRun.assessments` 包含每项结果及独立 `validity`，可作为候选数据源。实施前应以真实或契约样本核对：四态计数总和等于 assessments 数量；未分析候选不计入；stale 是独立标记；列表筛选不改变整次 run 的范围；请求失败不把旧结果当新鲜结果。业务语义需 M3 核对，不能据此宣称图形已验收。

Windows；Node v24.14.0、npm 11.9.0；锁定依赖已安装，Playwright 配置使用本地 Edge。`npm run build` 与 `npm test` 在沙箱内因 esbuild spawn EPERM 启动失败，在授权环境重跑分别通过和 42/42 通过。浏览器回归结果见 M2 日志。尚未验证真实 HTTP、会话权限、物理移动设备和人工无障碍；登录/注册、字段兼容性与切换窗口等待 E1 草案和 M1 确认。
