## 环境与使用方法

- 已打开 `http://127.0.0.1:5173/`：真实 HTTP、本地专用 `huice_m2_phase3_test` 库、fixture 模式。仅输入合成资料；审核发布会写入这个测试库，不会发布正式政策。此前测试留下的合成记录会出现在列表中。
- 页面顶部可切换固定样例。真实模式用于验证真实 API 往返；固定样例只验证预置展示。切换或刷新会清空当前页面会话，先记录运行 ID、截图及报告。
- 后台令牌由本机测试环境提供，不写入文档或提交；仅用于隔离环境。政策正文可选 `apps/web/src/tests/fixtures/phase5-synthetic.txt`，源链接 `https://www.gov.cn/` 只是占位。
- 云端：M1 在远程主分支 `infra/README.md` §4.4 记录 2026-11-03 已部署 HTTPS 同源站点；M2 尚未独立完成联合验收，现场需先核实当前可用性、受限会话和测试授权。重新构建同源前端时使用 `VITE_API_BASE_URL=/api/v1`，按远程主分支 `infra/deploy/README.md` §3.3 操作；自签证书不提供可信身份，不输入真实企业资料。
- 结果记录模板：编号｜通过/失败/阻塞｜实际结果｜截图/运行 ID｜备注。

| C02 | 输入本机测试令牌，读取草稿，切换筛选和分页，打开一条草稿、离开再重入 | 列表与筛选一致；详情版本和状态正确；已保存内容可恢复。后台游标分页默认每页 20 条、最多 50 条；验翻页需先在专用测试库准备超过一页符合筛选条件的草稿。 |

## D. 错误、异常与状态分支

以下需隔离环境故障注入或测试工具配合；普通页面不能可靠触发的记“阻塞”，不要把模拟结果记成真实服务通过。

| 编号 | 场景 | 理想结果 |
| --- | --- | --- |
| D01 | 网络中断、API 503、恢复 | 显示可理解错误和可用 traceId；保留输入、不自动重发写请求；恢复后可安全重试。 |
| D02 | 401、受限会话 403、404 | 本地 `local` 不校验会话。`restricted` 下受门禁保护的公开业务接口缺失/无效会话返回 403 `DEMO_SESSION_REQUIRED`；后台接口先验 Bearer：缺失/错误返回 401 `UNAUTHENTICATED`，Bearer 正确但会话无效返回 403 `DEMO_SESSION_REQUIRED`。区分 404，清除受限数据，不回退固定样例；受限会话需 restricted 环境或专用模拟验证。 |
| D03 | 画像或草稿 ETag 409/428、缺失/弱 ETag | 保留编辑并提示读取最新版本；不覆盖他人修改；缺强 ETag 不执行写入。 |
| D04 | 抽取/导入/发布响应丢失、重复点击、同键重试 | 写入状态不确定时先核对；禁直接重复发布或导入；抽取重试遵循服务端幂等边界。 |
| D05 | 模型降级、轨迹失败、报告下载返回 JSON 错误 | 清楚标识实际模式、降级及失败；规则判断不伪称模型生成；报告错误不能下载成成功报告。 |
| D06 | 错误身份/版本/未知枚举、旧请求晚返回 | 显示契约错误，不默认满足；旧响应不能覆盖当前界面或恢复已退出的授权。 |
| D07 | 空列表、加载、无数据、关闭窗口 | 空态与筛选条件一致；加载有反馈和防重；关闭窗口仅看历史。 |

记录执行数、通过/失败/阻塞数、运行 ID、样本和证据路径；逐项列明缺陷及复测。P0 范围和最终判定按 [M3 功能验收清单](../../docs/product/ACCEPTANCE.md)及项目开发计划，界面安全与访问问题一并记录，关键项失败或阻塞时不宣布整体 P0 通过。固定样例、fixture、模拟错误与正式政策/真实模型/云端分别统计。云端入口已有 M1 历史部署记录，受限入口、同源 cookie 和跨设备访问仍待 M2 联合验收。
