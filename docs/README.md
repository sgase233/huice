# 项目组文档导航与扩展协作入口

> 更新：2026-11-09。适用于项目负责人、M1、M2、M3。#46—#48 的计划、设计、决策与验收均保存在仓库共享文件中；成员不需要读取本机交接文件或聊天记录才能开始工作。

## 1. 全员先读

1. [开发计划](DEVELOPMENT_PLAN.md)：当前进度、issue 已确认范围、E0—E4 顺序、分工、D1—D6 待决事项。
2. [扩展接口与数据约束](EXTENSION_INTERFACES.md)：账号权限、候选生命周期、图表数据来源、统计口径、接口草案及迁移边界。
3. [验收清单](product/ACCEPTANCE.md)：原功能与扩展分别留证，按用例 ID 核对是否可交付。
4. [工作手册](../WORKING_GUIDE.md)：文档维护责任、分支、提交、推送与交叉评审规则。

本轮顺序是**先明确契约与数据口径 → 账号和归属 → 推荐与分批图形 → 联合验收**。可复用现有数据的展示先行；本人轨迹和全局统计接口不得在服务端权限完成前开放。原最终验收继续推进，扩展日期待估工确认。

| 成员 | 重点阅读 | E0 第一批交付 | 后续实现与交接 |
| --- | --- | --- | --- |

| M2：前端/集成 | 扩展接口第 2—5 节；[前端说明](../apps/web/README.md)；[UI 简报](ui/UI_BRIEF.md) | 复核登录恢复、权限错误、候选过期/重试、图表空态及字段可用性；确认消费者兼容和部署顺序 | 按签收契约生成类型、接 API 与页面；将请求/响应、浏览器用例和截图交 M1/M3；不自行补资格结果或趋势数据 |
| M3：政策/产品/验收 | 开发计划第 2 节；扩展接口第 4—5 节；[政策范围](product/POLICY_SCOPE.md)；[验收清单](product/ACCEPTANCE.md) | 提供首批网址/正文与附件样本；签认完整度分组、适用字段/期间和不适用规则；核实日期来源、审核完成事件与统计口径 | 将业务定义及样本交 M1/M2；审核抽取和图表中文语义；执行并复核验收，不要求编写业务代码 |

**交接最低内容：**工作包/issue、对应 D 编号或验收 ID、文件位置、当前状态、输入样本、预期输出、未决问题和接收人。接口交接另附契约版本、成功/失败响应、权限与迁移说明；收到文件不等于签收。

## 4. 共同状态与更新方式

- **范围已确定**：负责人已明确要做什么；不代表接口已冻结。
- **待评审设计**：已有建议，D 项尚未关闭；可以估工、准备样本，依赖未定项的实现须等结论。
- **契约已签收**：有对应 OpenAPI/示例、评审人及记录；M1/M2 按同一版本实现。
- **已实现待验收**：有代码/测试证据，仍需联合或业务验收。
- **已验收**：验收清单有环境、样本、预期/实际、证据和复核结果。

新增功能目前是“范围已确定、设计待评审”，没有三方签收记录。D 项定案后更新开发计划的决策记录和接口设计对应段；实现后同步现行说明、OpenAPI、类型及验收。各模块 README 只作导航与局部实现说明，避免复制整套计划后各自漂移。
