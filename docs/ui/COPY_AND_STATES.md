# 界面文案与状态（M3）

| 状态 | 建议标签 | 必须给出的下一步 |
| --- | --- | --- |
| satisfied | 条件初步满足 | 查看依据并请经办人复核 |
| not_satisfied | 不满足条件 | 查看未满足的条款 |
| insufficient_evidence | 还缺资料 | 回答优先问题或补充证据 |
| conflict | 条款待人工核对 | 查看冲突原文，不提供申报建议 |
| stale | 依据已失效，待复核 | 查看变化并重新分析 |
| closed | 申报窗口已关闭 | 查看历史信息，不显示立即申报 |

涉税页面与报告固定提示：政策信息辅助整理；非税务专业意见；申报前请企业财税人员核对。M3 后续补充空态、加载态、API 失败与 MaaS 降级文案，M2 不自行改变业务含义。
