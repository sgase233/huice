### 2.2 D4 完整度

**已明确（负责人方向 + 现有数据）**

- 完整度 = 已填写适用字段数 / 适用字段总数；未知/未填写不计完成，不适用不入分母。
- `0`、`false`、`verified=false` 是已填写；缺失不是 0；不适用不能由缺值推断。
- 计数单位是 `(FactKey, 事实期间)`，不是 18 个键各一格。
- 分母为 0 时 `ratio=null`；存在适用性未知项时不显示总百分比。
- 完整度只反映填写情况，不代表资格/获批概率。

**M3 建议（待三方确认）**

- 四组：基础与资质（5）/经营与财务（8）/研发情况（4）/合规与信用（1）。
- `creditRecord` 单列“合规与信用”，理由见 COMPLETENESS_SPEC §4.1；三组方案是次选。
- 默认 scope：画像页用当前已发布政策最新版本；run 页用该 run 的 `policyVersionMap`；`closed` 历史样本不计入。
- 未来季度用 `not_due` 不入分母；`answered_unknown` 与 `not_answered` 分开显示。
- OR/AND 分支适用性优先做可达性判断；若本轮不做，必须用静态引用统计并在 `definitionVersion` 标注。

**仍待 M1/M2/M3 确认**

### 2.3 D5 统计

**已明确（负责人方向 + 现有实现）**
