# 界面文案与状态（M3）

## 1. 四态与失效/关闭状态

| 状态 | 建议标签 | 必须给出的下一步 |
| --- | --- | --- |
| satisfied | 条件初步满足 | 查看依据并请经办人复核 |
| not_satisfied | 不满足条件 | 查看未满足的条款 |
| insufficient_evidence | 还缺资料 | 回答优先问题或补充证据 |
| conflict | 条款待人工核对 | 查看冲突原文，不提供申报建议 |
| stale | 依据已失效，待复核 | 查看变化并重新分析 |
| closed | 申报窗口已关闭 | 查看历史信息，不显示立即申报 |

- `stale` 是叠加在四态之上的独立标记，页面同时显示原四态与「依据已失效，待复核」，不能覆盖原结论。
- `closed` 是政策状态，历史样本灰显且无「立即申报」动作。

## 2. 涉税固定提示（页面与报告一致）

> 政策信息辅助整理；非税务专业意见；申报前请企业财税人员核对。

资金项目另附：不承诺补贴到账，不代企业提交申报。

## 3. 空态 / 加载态 / 错误态 / 降级态

| 场景 | 文案 | 说明 |
| --- | --- | --- |
| 机会列表为空 | 暂无匹配政策 | 提示可调整筛选或完善企业画像，不猜测结论 |
| 政策详情无已发布版本 | 该政策尚未发布可查看内容 | 未审核规则不参与判断 |
| 企业画像缺事实 | 该字段未填写 | 缺失与 `0` 分开显示，不写 0 代替 |
| 加载中 | 正在分析，请稍候 | 同步请求，避免重复提交 |
| 网络/接口失败 | 暂时无法获取结果，请稍后重试（traceId 已记录） | 不吞掉错误，显示 traceId |
| 模型（DeepSeek）降级 | 解释内容为已保存结果，规则判断不受影响 | 模型失败时规则结果照常返回，不伪称实时调用 |
| 无权限访问后台/轨迹 | 无访问权限 | 管理接口需授权，不展示后台数据 |
