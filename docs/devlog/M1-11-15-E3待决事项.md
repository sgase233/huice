## 1. M1 需要说明的：可观测状态与覆盖证据（回答 D-3/D-7）

B3 能拿到的原始事实只有四类，覆盖状态由它们推导，不猜：

| 事实 | 覆盖含义 |
| --- | --- |
| `policy_version.imported_at` | 新草稿：**历来可读**，`newDrafts` 通常 `precise`；缺失即 `partial` 并给起点 |
| 发布事件（`policy_review_event`，来自 B3 基线） | 审核完成：`T_review` 之前 `partial`（基线按 `reviewed_at` 回放）；`legacy_source='unknown'` 且当天依赖它 → `null` + `LEGACY_PUBLISH_TIME_UNKNOWN` |
| `collection_baseline.run_lifecycle_from`（`T_run`） | 运行趋势：`T_run` 前 `failed`/`unfinished`/耗时一律 `not_collected`；`total`/`succeeded` 只能是「已记录数」并标 `partial` |
| `assessment_run` 锁两列（`lock_owner_pid`/`started_at`） | 只有 B2 之后的运行可判定「是否仍在跑」 |

**扫描关闭 ≠ 未采集**（M2 点名的区分）：运行记录与中断扫描是两件事。

- 运行记录：`begin_run` 在评估一开始就写 `running` 行，**与扫描开关无关**，所以这些运行照常计入 `total`/`unfinished`；
- 中断扫描：只影响「崩溃残留的 `running` 行会不会被标成 `interrupted`」。开关关闭时它们停在 `running`，在趋势里仍算 `unfinished`，**不会被排除**；
- 因此 `not_collected` 只用于 `T_run` 之前的时段；扫描关闭状态下 `unfinished` 的覆盖仍是 `precise`，但要给一个 `notes`：「中断恢复扫描未开启，崩溃残留的运行会停留在 running」。

## 3. M1 要交的响应样例（B1b / B3 / B4）

### D-1 `dateProvenance`：按真实记录给完整样例

顶层 `note`、`derived.basis`、`derivedFrom` 都要保留——它们承载多批次窗口说明与推算依据：

```json
"dateProvenance": {
  "version": 1,
  "effectiveFrom": { "status": "verified", "source": "body", "locator": "第十七条「自印发之日起施行」", "note": null },
  "effectiveTo": { "status": "derived", "source": null, "locator": null,
                   "basis": "办法第十七条「有效期 5 年」；按 2026-02-24 起算得 2031-02-23，满 5 年口径可能差一日",
                   "derivedFrom": "2026-02-24", "note": null },
  "applicationWindow": { "status": "unknown", "source": null, "locator": null,
                         "note": "2026 年度窗口见年度申报指南；该指南不属于本版本来源，未标 verified" },
  "note": "申报窗口不得当作政策有效期；多批次窗口与办理方式见本条 note"
}
```

语义约定：

- 旁表**没有行** → 整个 `dateProvenance = null`（「从未记录来源」，与「记录为未知」不同）；
- `status=verified` 必有 `source` 与 `locator`；`derived` 必有 `basis`，`derivedFrom` 可空；
- `applicationWindow.status=not_applicable` 表示该政策没有申报窗口（资格认定类）；
- 任何字段都不得因为「有值」就显示为 `verified`。

### D-3 指标响应（按指标覆盖）

```json
{ "date": "2026-11-20",
  "newDrafts": 2, "reviewsCompleted": 1, "pendingAtEndOfDay": 2,
  "availability": {
    "newDrafts":          { "state": "precise" },
    "reviewsCompleted":   { "state": "partial", "coverageFrom": "2026-11-20T10:00:00+08:00" },
    "pendingAtEndOfDay":  { "state": "precise" }
  },
  "dayOpen": false }
```

当天未结束：`pendingAtEndOfDay=null`、`dayOpen=true`，`newDrafts`/`reviewsCompleted` 为暂计数并标 `partial`。
