# UI 设计简报（M3 起草，M2 实现）

**用户：**中小企业负责人、财务人员、项目申报人员。**首要任务：**理解“为什么匹配/不匹配、缺什么证据、下一步做什么”。

页面顺序：企业画像 → 机会列表 → 政策详情/证据 → 准备清单/报告；审核页与轨迹页仅供团队受限演示。

设计需同时呈现四态结果与独立的“依据已失效”标记；历史窗口不得展示申报按钮。政策出处优先于装饰。下文为首版低保真线框、页面宽度、颜色/排版与移动端建议，M2 转为组件后请 M3 复核中文语义。

## 1. 全局视觉方向

| 项 | 建议 | 理由 |
| --- | --- | --- |
| 页面宽度 | 桌面最大内容宽度 1280px，正文栏 720px | 政策原文较长，控制行宽保证可读 |
| 字体 | 系统字体栈（PingFang SC / Microsoft YaHei / sans-serif）；正文 16px、辅助 14px、标题 20/24px | 中文正文不小于 14px |
| 颜色 | 中性灰为主，四态用单一强调色系；来源链接用标准蓝色下划线 | 政策内容优先，避免过多装饰色 |
| 四态配色（建议） | satisfied 绿、not_satisfied 红、insufficient_evidence 琥珀、conflict 紫；stale 一律叠加灰底「已失效」角标 | 四态与失效标记可同时读 |
| 排版密度 | 政策详情逐条条件各成一块，引用片段单独缩进 | 便于逐条回查原文 |

┌─────────────────────────────────────────────────────┐
│ 企业画像                           [重新分析]        │
├─────────────────────────────────────────────────────┤

### 2.3 政策详情页（核心）

```text

│ 版本: 财政部税务总局公告2023年第12号  有效期至2027-12-31│
├─────────────────────────────────────────────────────┤
│ 条件1 不属于国家限制和禁止行业      [满足]             │
│   事实: 2026 行业 C39 电子设备制造  来源: 用户填写      │
│   原文: “从事国家非限制和禁止行业” (第五条) [官方原文↗] │
│ 条件2 应纳税所得额≤300万元         [满足]             │
│   事实: 2026 应纳税所得额 280万    来源: 用户填写        │

│ 条件3 从业人数≤300人               [证据不足]          │
│   （全年季度平均值，含劳务派遣人员）                    │
│   [缺失: 2026 各季度从业人数]       [优先问题: 请补充]  │
│ 条件4 资产总额≤5000万元            [证据不足]          │
│   （全年季度平均值）                                   │
│   [缺失: 2026 各季度资产总额]       [优先问题: 请补充]  │
├─────────────────────────────────────────────────────┤
│ 依据已失效标记: (政策/事实变化时叠加显示)              │
└─────────────────────────────────────────────────────┘
```

### 2.4 准备清单/报告页

```text
┌─────────────────────────────────────────────────────┐
│ 准备清单                       [下载报告 .md]         │
├──────────────────┬──────────────────────────────────┤
│ 税收优惠          │ 资金项目                          │
│  资料归集留存备查  │  申报窗口/材料/官方入口            │
│  财税复核提示      │  缺失材料标注                    │
│  税务机关原文链接  │  (关闭窗口仅历史信息)             │
├──────────────────┴──────────────────────────────────┤
│ 风险提示: 非税务专业意见；申报前请财税人员核对        │
└─────────────────────────────────────────────────────┘
```

### 2.5 后台审核页 / 演示轨迹页（受限）

```text
后台审核: 导入 → 待解析 → 待审核(逐条条件+引用校验结果) → 发布
轨迹页:   原文 → 抽取条件 → 校验 → 事实 → 求值 → 解释（顺序步骤，脱敏）
```

## 3. 移动端最小可读布局

- 单栏堆叠；条件结果块改为上下排列（结论在上、依据在下）。
- 表格在窄屏改为卡片；官方链接整行可点击。
- 报告页税收/资金两栏在窄屏上下堆叠。
- 后台与轨迹页仅桌面演示使用，不要求移动端。
