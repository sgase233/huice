## 3. 取证注意事项（踩过的坑，别重复）

1. **`runId` 必须来自云端**：本机临时库跑出来的 ID 在演示环境里查不到，M3 复核时会撞 404。
2. **取证要脱敏**：响应里不能出现连接串、`ADMIN_TOKEN`、OBS AK/SK；截图与粘贴前先过一遍。云端 admin 接口需要 `Authorization: Bearer <ADMIN_TOKEN>`，该值只从 `/etc/huice/api.env` 读进变量，不进命令行参数、不进截图。
3. **只读接口优先**：写接口（导入、抽取、保存条款、发布）会改演示数据。要写就先备一份库快照，或用一次性政策版本。
4. **判断类证据用已仲裁的条件**：自己构造的表达式不构成「真实原文上判得对」的证据（ACCEPTANCE.md 对 `conflict` 的同一标准）。

## 4. 三项不能写成「已通过」（与 ACCEPTANCE.md 口径一致）

- **`conflict`**：`labels.csv` 148 条里为 0，唯一可能的冲突位置在现有节选来源中找不到；**仅由单元测试覆盖**，不用构造数据充数。
- **档位边界**：三个计划样本不在当前数据中补充（比例条件已降为 `manual_review`，样本触发不到档位降级）。
- **`verified`**：当前没有任何已双人复核的合成证明材料，维持全 `false`。
