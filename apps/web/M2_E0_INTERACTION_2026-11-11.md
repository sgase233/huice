# M2-01 E0 交互与契约评审准备

日期：2026-11-11；基线 `aa5a63d`、现行契约 rc.9。以下为消费者方案，新增接口和错误码均须以 M1 的 E1/E2/E3 草案及签收为准；不是已实现行为或业务签认。现状及端点迁移见 [M2-00 盘点](M2_BASELINE_2026-11-11.md)。

## 三类入口

| 用户及入口 | 步骤与输入 | 状态、返回及下一步 |
| --- | --- | --- |
| 企业用户 | 注册：账号、密码和企业初始名称、期间、地区、行业；登录后恢复本人企业 → 编辑事实 → 选政策分析 → 详情/报告 | 分步校验保留已填值；提交中禁重复；注册成功提示登录；错误定位字段或给重试。返回前提示未保存；登录恢复失败给重新登录入口 |
| 审核员 | 通过服务端验证的审核员注册密钥注册或登录 → 读取本人企业／全局只读数据 → 授权审核及轨迹 | 无本人企业时提供创建入口，字段和注册时是否可选以 E1 草案确认；他人企业明确只读，写入由服务端拒绝。全局轨迹入口仅授权后提供 |
| 演示访客 | 首页明确选择固定样例或由 M1 提供的受限 HTTP 演示入口 | 固定样例不请求业务 API，刷新重置；服务端 demo 门禁与身份会话分开。门禁过期指向实际演示入口，不能伪装为账号登出或静默回退固定样例 |

## 会话和表单状态

| 场景 | 消费者预期 / 待确认 |
| --- | --- |
| 刷新 | 通过签收后的 me 接口恢复身份及本人企业；加载时不显示旧账号业务数据；失败给明确重试/登录路径。主题可保留 |
| 会话失效 | 401 清空敏感状态并可重新登录；403 显示无权限，404 按契约处理，不暴露他人对象。登录和注册必须能从失效 cookie 恢复，具体凭证优先级问 M1 |
| 退出、改密、换账号 | 退出成功或会话已失效后清空企业、run、详情、报告、审核草稿及令牌；请求代次隔离所有迟到响应。改密成功后重新登录；重复退出以最终契约为准 |
| 未保存输入 | 站内跳转、换账号、退出前提示；取消保留输入和焦点。浏览器刷新/关闭采用浏览器允许的提示，不承诺自定义文案 |
| demo cookie 与账号 cookie 并存 | 不能把 demo cookie 当用户身份；登录、公开端点、失效账号与 demo 门禁的优先级和清理职责需 M1 明确。不得根据前端筛选保证数据隔离 |
| 登录/注册网络错误 | 保留非密码表单内容；密码及密钥不写日志、持久化或 URL。请求进行中禁重复；失败按契约给恢复路径，不猜测注册是否已落库 |

## 扩展状态与提示

| 场景 | 页面表达及恢复 |
| --- | --- |
| 候选过期 | 标明不可再提交，保留可复制的用户输入；刷新候选状态，不自动复活或重复提交 |
| ETag 冲突 | 显示服务器版本已变化，保留输入并提供读取最新版本与人工对照；不盲目覆盖 |
| 幂等进行中 / 超时 | 显示请求仍在处理或结果未确认；按契约查询并以同一键重试，禁止重复生成键创建草稿 |
| 抓取失败 / 部分失败 | 展示服务端来源级状态与可用结果；不把失败写成无更新，过期候选不因失败恢复 |
| 未到期 / 无更新 / 预算限制 | 分别解释未执行、已执行无新增、受预算限制；limits 与下次时间以服务端回显为准 |
| 图表空 / 未知 / 缺测 / stale / 请求错误 | 空表示范围内无记录；未知表示值不可判定；缺测表示无覆盖；stale 标示旧结果；请求错误提供重试，不转换为零。文字或表格与颜色共同表达 |

## 交 M1 确认的契约差异

1. AUTH-01—07 的完整 schema、响应示例、401/403/404/409、密码规则和限流；审核员未绑定企业的注册与创建流程。现有 `EnterpriseInput` 必填事实是否复用。
2. Cookie、CSRF、Origin、跨源凭据和暴露响应头；登录/注册/登出/公开端点遇失效账号 cookie 或有效 demo cookie 的完整优先级。刷新恢复的缓存控制和登出幂等。
3. 原企业创建、事实 PATCH、run、报告、轨迹及后台端点的权限、旧 Bearer 范围、ETag、字段和历史响应兼容；逐端点对照 rc.9 与 client 严格校验，不以相同路径认定兼容。
4. DISC 进行中、过期、冲突、预算、失败、无更新及幂等重放的状态码、响应及可恢复操作；VIS 的覆盖、可用性和未知状态字段。业务字段及统计语义由 M3 核对。
5. E1 独立草案的基线 SHA、生成类型方式、版本与切换/回退窗口；草案在隔离输出检查，不覆盖现行生成类型。未收到签收前不接入正式身份 API。

本文件是供评审的本地工作产物，尚未发送或获得 M1/M3 确认；真实权限与账号隔离需隔离环境 HTTP 验证。
